Informativa sulla Privacy (Privacy Policy)

Ultimo aggiornamento: 19 Ottobre 2026

Quiz VDS-VL (VDS-VL Quiz Master) è un'applicazione web progressiva (PWA) didattica e gratuita progettata secondo i principi Offline-First e Privacy-by-Design. L'applicazione non dispone di server backend proprietari e non richiede la registrazione di alcun account per l'utilizzo delle funzionalità di studio ed esame.

1. Dati Memorizzati Localmente sul Dispositivo

Tutti i dati generati dall'utente durante lo studio sono archiviati esclusivamente nella memoria locale del browser sul dispositivo dell'utente tramite tecnologia IndexedDB (database locale VDSQuizDB) e localStorage:

  • Progressi e Statistiche Quiz: risposte fornite, conteggio errori e risposte corrette consecutive (sistema Leitner).
  • Storico Sessioni d'Esame: data, durata, punteggio ed esito delle simulazioni svolte.
  • Preferiti e Note Personali: quesiti salvati nei segnalibri e annotazioni di studio scritte dall'allievo.
  • Preferenze dell'Applicazione: tema grafico (Scuro/Chiaro/Auto), dimensione del testo, impostazioni vocali e pacchetti audio MP3 salvati nella CacheStorage del browser per l'uso offline.

L'utente ha il pieno controllo su questi dati e può eliminarli in qualsiasi istante tramite il comando "Azzera tutti i dati di studio" disponibile in Impostazioni → Gestione Dati.

2. Integrazione Google Drive e Dati Utente Google (OAuth 2.0)

L'applicazione mette a disposizione una funzione interamente opzionale di backup e sincronizzazione cloud tramite Google Drive, attivabile solo su iniziativa esplicita dell'utente nella sezione Impostazioni → Backup Cloud.

2.1 Ambiti di Accesso Richiesti (Google OAuth Scopes)

Quando l'utente collega il proprio account Google, vengono richiesti unicamente i seguenti ambiti ristretti e non sensibili:

  • https://www.googleapis.com/auth/drive.appdata: consente di salvare e leggere il file di backup all'interno della cartella di configurazione nascosta dell'applicazione (appDataFolder) sul Google Drive dell'utente.
  • https://www.googleapis.com/auth/drive.file: limita l'accesso ai soli file creati direttamente da Quiz VDS-VL (nello specifico il file vds_quiz_master_backup.json).

2.2 Modalità di Utilizzo, Archiviazione e Sicurezza

  • Nessun Accesso ad Altri File Personali: Quiz VDS-VL non può vedere, elencare, leggere, modificare o eliminare alcun altro file, cartella, documento o foto presente nel Google Drive dell'utente.
  • Comunicazione Diretta Browser ↔ Google: Il file di backup transita esclusivamente tra il browser dell'utente e le API ufficiali di Google (googleapis.com) su protocollo cifrato HTTPS. Nessun dato Google e nessun token di accesso vengono mai inviati a server esterni o dello sviluppatore.
  • Assenza di Condivisione con Terze Parti: I dati ottenuti tramite le API di Google non vengono mai condivisi con terze parti, né venduti, né utilizzati per profilazione pubblicitaria o per l'addestramento di modelli di intelligenza artificiale.
  • Revoca dell'Autorizzazione: L'utente può scollegare l'account dalle Impostazioni dell'app o revocare in qualsiasi momento i permessi dalla pagina Sicurezza Account Google — App di terze parti.

2.3 Dichiarazione di Utilizzo Limitato (Google API Services User Data Policy — Limited Use)

Italiano: L'utilizzo e il trasferimento da parte di Quiz VDS-VL a qualsiasi altra applicazione delle informazioni ricevute dalle API di Google rispetteranno la Normativa sui dati utente dei servizi API di Google (Google API Services User Data Policy), inclusi i requisiti di Utilizzo Limitato (Limited Use requirements).

English (OAuth Verification Disclosure): Quiz VDS-VL's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data accessed via drive.appdata and drive.file scopes is used solely client-side in the user's browser to back up and synchronize the user's study progress file (vds_quiz_master_backup.json) on their personal Google Drive, and is never stored on developer servers, shared with third parties, or used for advertising.

3. Riconoscimento Vocale e Microfono

Nella Modalità Mani Libere l'utente può facoltativamente abilitare i comandi vocali per rispondere ai quesiti. L'elaborazione vocale avviene tramite le API standard del browser (Web Speech API) solo quando il microfono viene attivato dall'utente. L'applicazione non registra, non archivia e non invia mai file audio vocali a server dello sviluppatore.

4. Statistiche Tecniche Anonime (Opt-Out)

Per individuare i quesiti ministeriali con il maggior tasso di errore e migliorare la stabilità dell'applicazione, Quiz VDS-VL può raccogliere metriche tecniche aggregate e anonime tramite la piattaforma europea PostHog EU (eu.i.posthog.com, ospitata nell'Unione Europea in conformità al GDPR).

  • Anonimizzazione Rigorosa: La registrazione delle sessioni visive (session recording) e il tracciamento automatico del DOM (autocapture) sono disabilitati. Un filtro client-side rimuove qualsiasi campo potenzialmente personale (note di studio, email, token, trascrizioni).
  • Disattivazione a 1 Tocco (Opt-Out): L'utente può disattivare in qualsiasi momento l'invio delle statistiche anonime tramite l'interruttore "Statistiche d'Uso Anonime" presente in Impostazioni → Gestione Dati. L'applicazione rispetta inoltre l'impostazione Do Not Track (DNT) del browser.

5. Diritti dell'Utente e Contatti

In conformità al Regolamento UE 2016/679 (GDPR), l'utente può in qualsiasi momento esportare integralmente i propri dati di studio in formato aperto .json, modificarli o cancellarli definitivamente dal proprio dispositivo e dal proprio Google Drive.

Per richieste di chiarimento o segnalazioni relative alla privacy è possibile aprire una segnalazione sul repository ufficiale del progetto: https://github.com/alessandroame/Quiz_VDS-VL/issues.
